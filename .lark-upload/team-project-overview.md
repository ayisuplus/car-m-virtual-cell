## 一、项目一句话定位

**面向剑桥大学 Pietro Liò 教授（图注意力网络 GAT 的共同发明人）汇报的 CAR-M 虚拟细胞模拟器** —— 一个用**真实癌症多组学数据 + 图神经网络（GNN）+ 机制模拟引擎**驱动的、在浏览器里实时运行的**免疫疗法计算沙盒**。

（白话：我们把「真实乳腺癌病人的多组学数据」喂给「教授发明的 GAT 图神经网络」，再用它驱动「一个模拟巨噬细胞怎么杀肿瘤的动画」，全部在网页上跑，不需要服务器。）

## 二、项目背景（为什么做这件事）

### 1. CAR-M 是什么？
- **CAR-T**（嵌合抗原受体 T 细胞）是血液肿瘤免疫治疗的明星，但在**实体瘤**上一直有三大难题：**进不去**（浸润困难）、**被压制**（免疫抑制微环境）、**抗原太乱**（异质性）。
- **CAR-M**（CAR 工程化巨噬细胞）是新兴替代方案：巨噬细胞**天然能钻进实体组织**，而且兼具**吞噬肿瘤细胞、呈递抗原、重塑微环境**三重能力。第一个进入人体临床试验的 HER2 CAR-M（代号 **CT-0508**）早期数据安全性良好。

### 2. TME（肿瘤微环境）是什么？
肿瘤不是一个孤立的细胞团，周围还有缺氧、乳酸堆积、TGF-β 等抑制性细胞因子、致密的细胞外基质（ECM）——这个整体叫**肿瘤微环境（Tumor Microenvironment, TME）**。它决定了免疫细胞「打得动还是打不动」。

### 3. 痛点与我们的解法
CAR-M 的设计空间巨大（信号域 × 靶抗原 × 亲和力 × 检查点阻断策略），又和 TME 条件深度耦合，**光靠人脑直觉很难比较设计方案** → 于是我们用**计算模拟**造一个「数字沙盒」，让设计方案在屏幕上先跑起来、先比一比。

> **重要定位声明**：本平台是「假设生成与机制趋势探索」工具，**不做临床预测**。所有数字输出都应理解为不同设计之间的**相对、方向性**比较，最终需要实验校准。

## 三、重构后的技术架构（核心，请重点理解）

项目经历了一次**深度重构**：数据从「合成数据」升级为「真实 TCGA 癌症数据」，模型从「MLP 代理模型」升级为「GAT 图注意力网络」。整体分五层：

```
┌─────────────────────────────────────────────────────────┐
│  前端层  React + Three.js 3D 可视化 + TCGA 参考面板 + 注意力热图  │
├─────────────────────────────────────────────────────────┤
│  引擎层  ABM 机制引擎 + GAT 代理模型（双轨运行）                    │
├─────────────────────────────────────────────────────────┤
│  模型层  GAT（图注意力网络）2 层 4 头，替代原 MLP 代理模型            │
├─────────────────────────────────────────────────────────┤
│  图构建  STRING PPI 蛋白质互作网络（真实生物学网络）               │
├─────────────────────────────────────────────────────────┤
│  数据层  TCGA-BRCA 真实癌症多组学（752 样本 × 5000 基因 × 4 组学层） │
└─────────────────────────────────────────────────────────┘
```

### 1. 数据层：TCGA-BRCA 真实多组学
- **数据来源**：TCGA 泛癌症图谱（TCGA-BRCA，乳腺癌）。
- **规模**：**752 个真实患者样本** × **5000 个高变基因** × **4 层组学**。
- **4 层组学**（同一个病人、同一批基因，四种分子视角）：
  1. **mRNA 表达**（这个基因表达多少）
  2. **突变**（这个基因有没有变异）
  3. **CNV 拷贝数变异**（这个基因复制了几份）
  4. **DNA 甲基化**（这个基因被「沉默」了没有）
- 数据经过质控、标准化、层间基因对齐、样本交集匹配，产出统一数据集。
- 白话：「**真实乳腺癌病人的数据**」，不是随便造的假数据——这是本项目最强的底气之一。

### 2. 图构建：STRING PPI 蛋白质互作网络
- 基因不是孤立的，而是**通过「蛋白质-蛋白质互作（PPI）」连成一张网**。
- 用真实生物学数据库 **STRING** 构建高置信度互作网络（置信度阈值 ≥0.7）。
- **完整图规模**：5000 个节点（基因），约 **60000 条无向互作边**（120000 条有向边）。
- 大白话：每个基因是网络里的一个「节点」，基因之间「认识、有往来」就连一条「边」。这张网就是 GNN 的「底图」。

### 3. 模型层：GAT 图注意力网络（本次重构的核心）
- **GAT（Graph Attention Network，图注意力网络）**：一种图神经网络，能学习「在一张图里，哪些邻居更重要」，并给每个邻居算一个「注意力权重」。
- 本项目 GAT 配置：**2 层、4 头注意力**，替代原来的 MLP 代理模型。
  - 前端推理版：输入 24 维特征 → 中间 16 维 × 4 头 → 输出 3 维决策，**约 268 个参数**，轻量到浏览器实时可跑。
  - 训练版：用 5 折交叉验证训练，输出免疫浸润、免疫亚型、生存风险三类预测。
- **为什么用 GAT 而不是 MLP**：MLP 只看单个基因，GAT 还能同时看「基因与基因之间的互作关系」——这正好匹配肿瘤微环境里「多基因协同」的生物学本质。
- **突破性一点**：GAT 是 **Pietro Liò 教授共同发明**的架构（ICLR 2018，被引 30,000+ 次）。用 GAT = 用「教授自己的方法」来向他汇报。

### 4. 引擎层：ABM 机制引擎 + GAT 代理模型「双轨运行」
- **ABM（Agent-Based Modeling，基于智能体的建模）**：在屏幕上一个一个模拟细胞个体的行为——CAR-M、野生型巨噬细胞、肿瘤细胞、CD8+ T 细胞四类细胞在同一个微环境里实时运动、互相作用。
- **双轨**：机制引擎（基于生物规则的 ODE 机制）与 GAT 代理模型（神经网络快速近似）并行。GAT 替代了每细胞的极化计算，实测约 **8 倍提速**（surrogate ~1.6µs/细胞 vs ODE ~13.5µs/细胞，11 次计时中位数）——这是让「屏幕上上百个细胞每帧都做决策还能 60fps 流畅」的关键。
- **确定性可复现**：使用固定随机种子，同样参数每次跑结果 bit 级一致，保证 A/B 对比诚实可信。

### 5. 前端层：React + 可视化
- **React + TypeScript** 单页应用，Vite 构建，**完全浏览器端运行，无后端**。
- **Three.js 3D 可视化**：DNA 双螺旋等 3D 模型查看器。
- **TCGA 参考面板**：把 GAT 对真实病人的预测（免疫浸润、免疫亚型、生存风险）可视化。
- **注意力热图**：把 GAT 学到的「哪些基因通路更重要」用热图展示（可解释 AI 的落地）。
