# CAR-M Simulator 项目资料：PPT 与海报制作参考

> 本文档汇总项目概况与核心设计，供小组同学制作 PPT 和海报使用。

## 一、项目一句话介绍

**CAR-M Simulator**：一个机制启发型、浏览器端实时运行的 Agent-Based 计算模拟平台，用于探索 CAR 工程化巨噬细胞（CAR-M）在肿瘤微环境（TME）中的行为，辅助 CAR-M 疗法设计方案比较与假设生成。

## 二、背景与动机

1. CAR-T 疗法在血液肿瘤中效果显著，但在实体瘤中受限于：浸润困难、抗原异质性、免疫抑制性肿瘤微环境（TME）、毒性。
2. CAR 工程化巨噬细胞（CAR-M）是新兴替代方案：巨噬细胞天然能浸润实体组织，兼具**吞噬肿瘤细胞、抗原呈递、重塑微环境**三重能力。
3. 首个 HER2 靶向 CAR-M（CT-0508）人体临床试验报告了良好的早期安全性。
4. 痛点：CAR-M 设计空间巨大（信号域 × 靶抗原 × 亲和力 × 检查点阻断策略），且与 TME 条件（缺氧、乳酸、TGF-β、ECM 密度）相互作用复杂，人类直觉难以把握 → 需要计算沙盒。

**定位声明（重要）**：平台是"假设生成与机制趋势探索"工具，用于教学与实验优先级排序，**不做临床预测**。所有数值输出应理解为不同设计之间的相对、方向性比较。

## 三、核心设计（四层架构）

| 层 | 内容 |
|---|---|
| **数据层 Data** | 生物学先验：细胞因子角色、极化驱动因素、检查点生物学（来自文献与单细胞/TAM 图谱），作为可校准的模型结构 |
| **AI 层** | 神经替代模型（Neural Surrogate）：6→32→32→3 MLP，将局部细胞因子/代谢上下文映射为巨噬细胞极化状态，替代每细胞 ODE 积分 |
| **模拟层 Simulation** | ABM 引擎 + 10 因子反应-扩散场 + 检查点感知吞噬模型 + 趋化运动规则，涌现出群体行为 |
| **应用层 Application** | React + TypeScript 单页应用，Three.js 3D 资产查看器 + Chart.js 仪表板，全客户端运行、无后端 |

工程规模：约 **14,000 行 TypeScript / 93 个文件**，Vite 构建，完全客户端运行。

### 1. Agent-Based 引擎（模拟层核心）

- 4 类 Agent：CAR-巨噬细胞、野生型巨噬细胞、肿瘤细胞、CD8⁺ T 细胞
- 主循环：扩散场更新 → 空间索引重建 → Agent 感知与行动 → T 细胞克隆扩增 → 肿瘤增殖 → 清理死亡 → 统计采样
- 空间哈希网格（cell size 50）加速邻居查询，避免 O(n²)
- **确定性可复现**：种子 LCG 随机数生成器，默认种子 20250706，任何一次运行 bit 级可复现，保证 A/B 对比诚实性

### 2. 检查点感知吞噬模型（核心机制模块）

吞噬决策概率公式：

```
p_base  = (affinity/10) × antigenDensity
cd47    = 1 − CD47_expr × (阻断? 0.15 : 0.85)     # "别吃我"信号 CD47/SIRPα
cd24    = 1 − CD24_expr × (阻断? 0.20 : 0.55)     # 二级"别吃我" CD24/Siglec-10
m1Bonus = CD3ζ: 1+0.5·m1Score | FcRγ: 1+0.3·m1Score | MerTK: 1
p_final = clamp(p_base × cd47 × cd24 × m1Bonus × energy, 0, 1)
```

信号域带来**质的差异**：CD3ζ/FcRγ 标准吞噬（M1 加成）；CD147 不吞噬，改为分泌 MMP 降解 ECM（基质重塑）；MerTK 执行胞葬作用（仅攻击低活力靶细胞，概率加倍）。

### 3. 神经替代模型（AI 层亮点）

- 用 30,000 条合成样本（来自生物学动机的 ODE 模型）训练小型 MLP
- 替代每细胞 ODE 积分，实测 **约 8 倍加速**（1.61 µs vs 13.45 µs/细胞/决策，11 次重复中位数）
- 为浏览器内每帧、每 Agent 决策留出充足算力预算，保证交互流畅

### 4. CAR-M 设计工作台

可配置参数：信号域（CD3ζ / FcRγ / CD147 / MerTK）、靶抗原（HER2 / CD19 / EGFR）、亲和力（0-10）、检查点阻断开关（CD47/SIRPα、CD24/Siglec-10）；配合 TME 场景参数（氧、乳酸、TGF-β、细胞数量），支持多组实验并排对比。

### 5. 实时指标仪表板

6 项实时读数：肿瘤负荷、吞噬率、M1/M2 比例、CD8⁺ T 细胞激活、CAR-M 持久性等。

## 四、关键亮点数据（海报/PPT 可直接引用）

- ✅ 完全浏览器端运行，无服务器依赖，开放可复现
- ✅ 神经替代模型 ~8× 加速（1.61 µs vs 13.45 µs，可复现基准测试随代码发布）
