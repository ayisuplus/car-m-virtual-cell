# CAR-M Simulator · 统一展示 Deck 交付说明

> 面向 8 月英国访学项目展示。一个网页 deck 收编全部成果：叙事 + 实景截图 + 真实网站 live demo，翻页即演示，无需切窗口。

## 一句话结论

放弃「讲稿 + 网站 + PPT」三件套的割裂展示，综合成**一个网页版 HTML deck（11 页）**：
前半程用幻灯片讲清背景与方法，翻到截图墙看实景，最后一页直接把**真实运行的网站嵌进幻灯片**——现场可转 3D、拖滑块、跑模拟，全程不离开 deck。

## 打开方式（现场演示）

```bash
cd car-m-virtual-cell/app
npx vite preview --port 3000 --host      # 静态托管已构建好的 dist
# 浏览器访问：
http://localhost:3000/slides/index.html
```

- 键盘：`→ / 空格`下一页，`← `上一页，`Home/End`首尾页
- 编辑：按 `E` 进入内联编辑（改任意文字），`Esc` 退出
- Demo 页会自动加载真实网站；若网络/加载异常，3.5 秒后自动降级为高清截图，演示不中断

## 关键实现

- **同源部署**：deck 与网站同源（都在 `localhost:3000`），iframe 才能稳定嵌入。改动源文件后需同步：
  `cp slides/index.html dist/slides/ && cp slides/assets/shots/*.webp dist/slides/assets/shots/`
- **iframe 懒加载 + 降级**：仅在翻到 demo 页时才 set src；`load` 成功清除降级，超时/`error` 显示截图 fallback。
- **截图来源**：浏览器自动化直出 webp，存 `slides/assets/shots/`。

## 验证结果

- `curl` site / deck / shot 三项资源全 `200`
- 浏览器打开 deck 确认 `01 / 11` 十一页结构
- 跳转 LIVE DEMO 页，iframe 状态 `{"src":"http://localhost:3000/","hasSrc":true,"fallbackOn":false}` —— 加载的是真实网站，降级未触发
- 截图视觉确认 iframe 内为可交互的 CAR-M Simulator（3D Cell Viewer、TME Simulator、控制滑块、Start/Reset）
